☁ 手机 ↔ 电脑自动同步（云同步）
=====================================
1. 打开 GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens →
   Tokens (classic) → Generate new token，只勾选 gist 权限，生成后复制 token（ghp_...）。
2. 工作台「设置 → ☁ 云同步」：粘贴 token，建议再设一个「加密口令」，勾选「启用自动同步」，点「💾 保存配置」。
3. 点「⬆ 立即备份」首次上传；之后每次改动会自动备份到云端。
4. 手机用浏览器打开本永久链接，进入「设置 → ☁ 云同步」填入【同一个 token】并开启自动同步，即自动与电脑同步。
注意：token 与口令仅存本机浏览器；建议设加密口令，云端内容才加密。多设备同时改且未同步时，以「云端最新」为准。
